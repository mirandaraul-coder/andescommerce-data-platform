# AndesCommerce Data Platform

End-to-end Data Engineering project built with Azure Databricks, Delta Lake and Medallion Architecture.

## Business Scenario

AndesCommerce is an e-commerce company that needs to integrate data from multiple sources, including customers, products, orders, order details and payments.

The objective of this project is to build a scalable data platform using Azure Databricks to ingest, process, validate, transform and prepare reliable data for analytical consumption.

## Architecture

The project follows a Medallion Architecture:

Source Systems → Ingestion → Bronze → Silver → Gold → Analytical Model → Consumption
